# bob_sessions/

This directory contains Bob task-session screenshots for the PatchCourt hackathon submission.

## Naming convention
`<yourname>_task##_<description>_summary.png`

Example:
- `asmit_task01_baseline_tests_summary.png`
- `asmit_task02_security_auditor_findings_summary.png`
- `asmit_task03_coverage_auditor_findings_summary.png`
- `asmit_task04_fixer_union_find_summary.png`
- `asmit_task05_fixer_lru_cache_summary.png`
- `asmit_task06_fixer_hash_map_summary.png`
- `asmit_task07_verifier_union_find_acquitted_summary.png`
- `asmit_task08_verifier_lru_cache_acquitted_summary.png`
- `asmit_task09_verifier_hash_map_acquitted_summary.png`
- `asmit_task10_final_run_10_passed_summary.png`

## How to capture
Tasks tab → select task → click header → screenshot the consumption summary → save here immediately.
Do not reconstruct from memory at the end.
